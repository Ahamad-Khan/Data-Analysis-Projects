# Sales Performance Analysis

## Project Overview
This project focuses on analyzing sales data using Microsoft Excel to uncover key business trends and performance metrics. The final findings and strategic recommendations were documented in a comprehensive business report.

## Architecture & Tools Used
* **Dynamic Excel Dashboard:** Built an interactive presentation layer using **Excel Charts** driven by background Pivot Tables, utilizing **Slicers** for on-the-fly filtering.
* **Microsoft Word:** For documenting the final executive summary and analytical report.
* **Advanced Data Lookups:** Utilized 'INDEX', 'MATCH, 'VLOOKUP', and 'HLOOKUP' to dynamically reference and merge complex datasets.
* **Conditional Aggregations:** Applied 'SUMIFS', 'SUMIF', and 'SUM' to calculate tailored business metrics based on multiple criteria.
* **Data Cleansing & Logic:** Implemented a wide suit of logical, text and date functions (including 'IF', 'AND/OR', error-handling and text-cleaning formatting functions) to audit and prepare the raw data.
